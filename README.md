Backend:
        Luo ASP.NET Core -projekti ja lisää yllä oleva C#-koodi.
        Käynnistä: dotnet run.
        Testaa: GET http://localhost:5001/api/patient/1 (esim. Postmanilla).



Frontend:

        Luo React-projekti ja lisää yllä oleva TypeScript-koodi.
        Asenna Axios: npm install axios.
        Käynnistä: npm start.
        Avaa: http://localhost:3000.
    Testaus:
        Syötä ID (esim. 1), tarkista tiedot ja tallenna muistiinpano.
